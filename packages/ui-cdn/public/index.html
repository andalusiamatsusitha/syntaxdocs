Showcase & Pengujian Komponen UI Shared CDN

Komponen ini 100% netral bahasa (HTML, CSS BEM, dan Vanilla JS). Dapat dikonsumsi langsung oleh PHP, Node.js, Golang, maupun aplikasi web statis.

Berhasil: Aset UI CDN berhasil dimuat dengan performa maksimal dan zero-runtime framework.
Informasi: Semua interaksi (Modal, Dropdown, Dismiss) dikendalikan secara otomatis oleh core.js melalui attribute data-toggle.
